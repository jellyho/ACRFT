The patch-critic: a VLA-independent distributional value function for adaptive action chunking

A frozen dense-vision critic that scores a policy's candidate action chunks and decides how far to commit to each — trained with distributional IQL on offline rollouts, never touching the VLA's weights.

work in progressRoboCasa 365π0.5 actorlogged · jellyho_/acrft

Adaptive-chunking RFT asks a value function two questions at every decision point: which of the chunks a vision–language–action (VLA) policy proposes is best, and how far to commit to it before re-planning. This note describes the critic we use to answer both — the patch-critic — as a self-contained method: its observation, architecture, distributional objective, and deployment rule. The critic is deliberately independent of the VLA: it reads a frozen dense visual representation rather than the policy's internal tokens, so it can be trained and swapped without retraining the actor.

1Setup — the chunked MDP

The actor is a fixed VLA policy π that, at state st, samples an action chunk: a length-H sequence a=(a1,…,aH), here H=16. We work in the induced chunked MDP — an action is a chunk, and the environment returns the discounted reward accumulated while it executes. Reward is sparse and binary: r=1 on task success, else 0.

Adaptive chunking lets the executed length vary. For a chunk a at st and a commitment horizon h, the value of committing to the first h steps and then acting on-policy is

Qh(st,a) = 𝔼[ ∑i=0h−1 γi rt+i + γh V(st+h) ](1)

The critic emits Qh for a fixed set of horizons h∈𝒦={2,4,…,16} in a single pass, on one shared discounted scale — so both questions are answered at once: the best chunk maximises the full-horizon value, the best commitment maximises value across horizons (§6).

2Observation — a frozen dense-patch grid

Most VLA critics compress an observation into a single pooled vector. We found such a global token to be nearly action-blind — it cannot separate a good chunk from a bad one, so selecting by it is inert or harmful. Following the Patch Policy insight, the patch-critic keeps the full spatial grid of a frozen self-supervised ViT (DINOv2), whose patch tokens carry strong local geometry: where each object is, where contact will happen — exactly the signal a manipulation value function needs.

Each of three camera views is encoded by the frozen backbone into a 16×16 patch grid; we 2×2 average-pool to 8×8 to make attention affordable, then concatenate:

ϕ(s) = concatc∈{L,W,R} pool2×2(DINOv2(xc)) ∈ ℝ192×384(2)

The backbone is never updated (∇ϕ=0), so ϕ(s) is a fixed, cacheable map. The critic below is the only trained part.

2Architecture — a per-horizon value transformer

The critic fθ is a small transformer over one token sequence: the 192 patch tokens, a proprio token, and the chunk cut into M=H/g macro-group action tokens (group size g=2 ⇒ M=8). A block-causal mask lets every context token (patches, proprio) be seen by all action tokens, while action token j attends only to macro-groups ≤j. The value at position j is thus the value of committing to exactly the first j groups — one value per horizon, all comparable because they share the network and the discounted target scale.

3Distributional value with HL-Gauss

Both Q and V are distributional: each head predicts a categorical distribution over a fixed grid of m=51 value atoms z1<⋯m on [0,1]. To turn a scalar target y into a soft label we use the HL-Gauss projection Φ — a Gaussian of width σ centred at y, integrated over each atom cell of width Δ:

Φ(y)i ∝ ∫zi−Δ/2zi+Δ/2 𝒩(z;y,σ2) dz ,   ∑i Φ(y)i=1(3)

The scalar mean is V̄=∑i pi zi. Keeping the whole distribution matters twice: it stabilises value learning under sparse binary reward, and it lets the backup carry V's law forward — not just its mean (§4). Under aliased states whose returns genuinely branch between success and failure, only a distributional target can hold that spread.

4Objective — distributional IQL

We train offline from a fixed set of π0.5 rollouts with implicit Q-learning, so the critic never queries an out-of-data action. Three pieces are learned: the per-horizon critic fθ, a state-value Vψ, and a Polyak target θ̄.

Distributional Bellman target for Q

For a transition at frame t and horizon h, the target is the pushforward of Vψ's categorical law at st+h under the affine map z↦Gh+γhz, re-projected onto the fixed atoms:

Gh = ∑i=0h−1 γi rt+i(4)
𝒯h = ∑j=1m pψ,j(st+h) · Φ(Gh + γh zj)(5)

Terminal successors put all mass at their reward; where the behaviour policy's realised Monte-Carlo return GtMC exceeds the bootstrap mean we floor the target to it — a Cal-QL-style correction success-only data needs. The critic is fit by cross-entropy to this soft target over valid horizons and the K-critic ensemble:

ℒQ(θ) = − ∑h∈𝒦 𝟙valid · sg[𝒯h]⊤ log softmax fθ(ϕ(st),a)h(6)

Expectile value for V

IQL fits V to an expectile of Q over data actions — pushing it toward maxaQ without proposing an action. With residual u=Q̄θ̄(s,a)−V̄ψ(s) (ensemble-min Q̄) and expectile weight |τ−𝟙(u<0)|, and because V is distributional, we train it by expectile-weighted cross-entropy toward Q's demonstrated-action law — so V learns the upper-quantile distribution, not just its mean:

ℒV(ψ) = |τ − 𝟙(u<0)| · CE(pψ(s), sg[pθ̄(s,a)])(7)

The target follows by Polyak averaging θ̄←(1−ρ)θ̄+ρθ. Detaching Qθ̄ in (7) and Vψ in (5) keeps the halves from chasing each other through the shared optimiser.

Why V had to become distributionalV lives inside the Q target (Eq. 5): a mis-calibrated V mean poisons every bootstrap, and deployment reads Q. Making V distributional and bootstrapping its full law is what lets a return's branching survive the backup instead of being averaged away step by step.

5Deployment — best-of-N and adaptive-K

At state s the frozen actor samples N candidate chunks {a(1),…,a(N)} (stochastic flow-matching draws). The critic scores all of them in one batched pass, returning each candidate's per-horizon value Q̄(s,a(n))h. Two rules follow:

n★ = argmaxn Q̄(s,a(n))H  (best-of-N) ,  K★ = argmaxh∈𝒦 Q̄(s,a(n★))h  (adaptive-K)(8)

Best-of-N commits to the full winning chunk. Adaptive-K executes only the winner's most-valuable prefix K★, then re-plans — short chunks near contact events where value falls off fast, long chunks in free space where committing further is safe. Candidates are never stored; they are re-sampled from the actor at decision time, exactly as the offline IQL objective assumes.

6What is being tested

The method makes one falsifiable promise: a value function trained this way should let chunk selection beat the raw actor. The current experiment measures exactly that on RoboCasa 365 — the actor's own success rate (no selection) versus best-of-N and adaptive-K under the same critic, across four atomic tasks — and pits the scalar-V ablation against the distributional-V model of this note. Training curves are logged under jellyho_/acrft; the first (scalar-V) run did not yet clear the baseline, which is what motivated the distributional V here.
