🌙 밤샘 실험 보고서 — 싼 표현(cheap-z)과 Model-Based AC

2026-08-07 아침 · PrepareCoffee 514 에피소드 / 279,534 프레임에서 전부 직접 측정

⚡ 세 줄 요약

1  성공: 22M짜리 frozen DINOv2 + 15분 학습한 헤드가, 3B VLA에서 뽑던 토큰을 모든 값-probe에서 이겼습니다. 인코더 크기 1/130, annotation 파이프라인 삭제.

2  반전: 그런데 진짜 병목은 표현이 아니라 critic이었습니다. 성공 데모만 있는 데이터에선 어떤 IQL critic도 action을 구분 못 합니다 (best-of-N이 사실상 동전던지기였음을 측정으로 확인).

3  해법: dynamics 모델 앙상블의 "불일치(disagreement)"가 유일하게 action을 구분하는 오프라인 신호였습니다 → model-based AC로 가는 근거가 이론이 아니라 측정으로 확보됨.

0 왜 이걸 했나

지금까지 critic의 입력 z는 3B VLA의 hidden state에서 뽑았습니다. 문제 세 가지:

  • 💸 비쌈 — critic 실험 하나 하려면 데이터셋 전체에 3B forward를 돌리는 annotation이 필요 (수 시간, 이번에도 4번 실패)
  • 🏠 외형 편향 — SigLIP feature는 "어떻게 생겼나"의 함수라, 부엌마다 다른 RoboCasa에선 z가 "몇 번째 데모인가"를 외워버림 (episode 판별 100%)
  • 🐢 느린 반복 — 표현을 바꾸려면 VLA를 하루 재학습

그래서 어젯밤 목표: "LeRobot 데이터에서 바로 학습하는 싸고 좋은 표현"을 찾고, 월드모델까지 활용하는 그림 그리기.

2 반전: critic이 action을 안 보고 있었다 발견

오프라인 진단 배터리를 두 critic(VLA-z용, cheap-z용)에 돌렸더니 둘 다 동일하게:

진단 결과 (원문)
"FAIL — action sensitivity ≈ 0: the critic ignores the action, best-of-N is a no-op"
후보 16개 chunk 간 Q값 차이가 0.001 수준 — 사실상 무작위 선택과 같았음

왜 이런 일이?

데모 514개가 전부 성공
모든 시연 action이
성공으로 이어짐
→
데이터에 "대조"가 없음
좋은 action vs 나쁜 action
비교쌍이 존재하지 않음
→
Q(z, a) → V(z)로 퇴화

학습 loss는 완벽히 내려감

이건 우리 버그가 아니라 성공-only 오프라인 데이터의 구조적 한계입니다. 문헌도 정확히 이래서 장치를 답니다 — V-GPS는 "IQL 랭킹은 후보 10개 넘으면 붕괴"를 ablation으로 보였고, RoboMonkey는 가짜 나쁜-action을 합성해서 학습하고, WCM은 dynamics로 critic을 접지합니다.

💡 의미: 지금까지의 best-of-N 실험들에서 "critic이 고른다"는 부분이 사실상 작동하지 않았을 가능성이 큽니다. 이걸 밤에 발견한 게 오히려 다행.

3 해법의 실마리: dynamics의 "불일치"가 답이었다 발견

그럼 뭐가 action을 구분하나? 세 가지 채점 방식을 같은 조건에서 비교했습니다:

채점 방식후보 간 변별력
(스프레드)		시연 chunk vs
엉뚱한 chunk 구분		판정
Q(z, a) — 기존 model-free0.0013실패action 무시
V(d(z, a)) — 값을 dynamics에 통과0.0011AUC 0.50 (동전)역시 무시
dynamics 앙상블 disagreement0.0253 (20배)AUC 0.58, margin +0.09유일한 신호
Q. disagreement가 뭐고 왜 작동하지?
dynamics 모델 5개를 독립적으로 학습시키고, 같은 (상태, action chunk)에 대해 5개의 미래 예측이 서로 얼마나 갈리는지를 잽니다. 시연된 것과 비슷한 chunk → 5개가 다 봤던 패턴 → 예측 일치. 이상한 chunk → 학습 데이터에 없음 → 예측이 제각각. 즉 "이 상태에서 이 행동이 시연자스러운가"를 재는 겁니다. 성공-only 데이터가 가르칠 수 있는 건 "어느 게 더 성공하나"(대조 없음)가 아니라 정확히 이것뿐입니다.

dynamics 모델 자체 품질 검증도 통과

  • 모든 예측 길이에서 "변화 없음" 기준선을 이김 (16스텝 예측에서 31% 낮은 오차)
  • disagreement ↔ 실제 오차 상관 ρ 0.70~0.78 → "예측이 자신 있는 만큼만 커밋한다"는 adaptive chunking 규칙이 성립 가능

단계별 계획

Phase 0
이번 주
오프라인 마감. critic에 Cal-QL 캘리브레이션(우리가 이미 가진 MC return으로 max(Q, MC)) + LayerNorm. dynamics v1 (조사로 확정한 레시피: macro-stride 4, 불확실성 헤드). stitching 갭 해소 시도 3종.
Phase 1
온라인
정책은 얼리고 critic만 온라인 정제. rollout에서 드디어 실패 데이터가 들어옴 → 그제서야 값-기반 랭킹이 살아남. 워밍업→50/50 버퍼 등 검증된 안정화 스택 사용.
Phase 2
VLA 개선
VLA 자체를 개선. Q-gradient로 chunk을 다듬고 그 결과를 flow에 증류 (Q-VGM 방식: 이미 로깅된 ~500 에피소드로 π0.5를 79→92.5% 올린 선례). flow에 PPO 직접 적용은 금지 — 실기기에서 아무도 안 하고, 하는 논문은 시뮬 전용.
